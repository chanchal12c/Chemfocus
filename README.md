🧪 ChemFocus

### Interactive Chemistry Learning Website for Undergraduate Students

🌐 **Live Website:** https://chemfocus.vercel.app

## About ChemFocus

ChemFocus is a web-based learning platform designed for undergraduate chemistry students who find difficult chemistry concepts hard to understand.

The website presents chemistry concepts in a simple and engaging way and provides students with different ways to learn, revise, and practice.

## Features

- 📚 Structured chemistry curriculum
- 🧠 Easy-to-understand topic explanations
- 🔬 Molecular insights for deeper conceptual understanding
- 📖 Revision notes and summaries
- ❓ Interactive practice quizzes
- ⏱️ Timed practice questions
- 📊 Quiz scores and performance tracking
- ⚖️ Comparison of related chemistry concepts
- 🎤 Viva preparation questions
- 🧪 Laboratory and practical chemistry content
- 🔎 Chemistry topic search
- 📱 Responsive interface for different screen sizes
